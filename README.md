# ELDO E-MOVE AI — Vercel-ready hackathon website

## Deploy to Vercel
1. Create a GitHub repository and upload `index.html` and `vercel.json`.
2. In Vercel, choose **Add New → Project**, import the repository and deploy.
3. Framework preset: **Other** (static site). No build command is required.
4. The resulting `*.vercel.app` address can be used as the live demo URL.

## Local test
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Next hackathon step

## Important
The numerical pilot targets on the page are proposed hackathon KPIs, not current Eldoret statistics. Live charger availability, tariffs, EV specifications and emissions factors should be validated before production use.
